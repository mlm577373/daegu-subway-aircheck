# 실제 결합 데이터

작성일: 2026-11-14. **이 폴더의 `merged_hourly_연도.csv`는 내부 공기질·승하차·실외 공기질 관측값을 실제로 결합한 파일이다.** 역 대응표만 있는 파일이 아니다.

## 파일

| 실제 결합 파일 | 행 수 | 포함 기간 |
|---|---:|---|
| `merged_hourly_2021.csv` | 370,204 | 2021년 4~12월 |
| `merged_hourly_2022.csv` | 495,323 | 2022년 전체 |
| `merged_hourly_2023.csv` | 488,762 | 2023년 전체 |
| `merged_hourly_2024.csv` | 497,552 | 2024년 전체 |
| `merged_hourly_2025.csv` | 161,739 | 2025년 1~4월 |
| `merged_hourly_2026.csv` | 160,364 | 2026년 1~4월 |
| **합계** | **2,173,944** | 기존 공통 수집 기간 53개월 |

CSV 6개 크기 합계는 약 538.6 MB이며 UTF-8 BOM이다. 전체 행 수가 Excel 한 시트의 행 제한을 넘으므로 연도별로 분리했다. 2025년 5~12월은 원래 수집에서 제외된 기간이며 이번에 추가하지 않았다.

- `merge_summary.json`: 연도별 행 수, 결합·결측 상태 건수, 파일 크기·SHA-256, 적용 가정.
- `validation_report.json`: 저장된 CSV를 다시 읽어 수행한 검증 결과.
- `columns.csv`: 열 이름 목록.

## 무엇을 기준으로 결합했나?

**기존 내부 공기질의 모든 관측 행을 기준으로 left join했다.** 매칭되는 승하차나 실외 값이 없어도 내부 행을 삭제하지 않았다. 없는 시간의 내부 관측 행을 새로 만들어 넣지도 않았다.

1. 내부 지점 57개를 호선별 승하차 역 번호에 연결했다. 같은 이름의 환승역도 호선별로 구분한다.
2. 승하차는 승차·하차 구분과 19개 시간대 열을 해당 역·날짜·시간 라벨에 연결했다.
3. 공식 역 좌표와 실외 측정소 좌표를 확보해, 수집한 도시대기 20개 측정소 중 직선거리가 가장 가까운 곳을 고정 대응으로 선택했다. **공간 대표성을 검증한 최종 선정이 아니라 초기 매칭**이다.
4. 현충로·율하는 공식 역 좌표의 표기 형식이 의심돼 실외 매칭을 보류했다. 이 두 역도 내부 공기질·승하차 행은 유지했다.

### 시간 규칙: 사용자 승인한 같은 시간 라벨 결합

추가 공식 설명·검색에서도 공기질 시간 라벨이 평균 구간의 시작인지 종료인지 확정하지 못했다. 사용자가 “안 나오면 같은 시간끼리 결합”하도록 승인하여 **`same_label_v1`**을 적용했다. 평균 구간이 일치한다고 검증된 데이터라는 뜻은 아니다.

| 내부 라벨 | 붙이는 승하차 열 | 붙이는 실외 라벨 |
|---|---|---|
| `2025-01-02:00` | 해당 열 없음 → 빈칸 | `2025-01-01 24` |
| `2025-01-02:05` | `2025-01-02`의 `h05_06` | `2025-01-02 05` |
| `2025-01-02:23` | `2025-01-02`의 `h23_24` | `2025-01-02 23` |

실외 `D일 24시`는 달력상 `D+1일 00시`로 처리했다. 같은 날짜의 00시로 바꾸지 않았으며, 평균 종료시각이라고 가정해 한 시간을 빼는 보정도 하지 않았다. 전년도 12월 31일의 24시도 다음 해 1월 1일 00시와 연결할 수 있도록 전체 수집 기간을 대상으로 조회했다. 수집되지 않은 이전 날짜의 자료는 추가로 만들지 않았다.

`time_key`는 현지 시간 라벨의 **연결 키**이며, 평균 구간 시작시각이 확인됐다는 뜻은 아니다. 한국 현지 시각 관례를 사용하며 UTC 변환은 하지 않았다. 승하차 00~04시는 원본에 시간대 열이 없어 0명이 아닌 빈칸이다.

## 열 설명

| 열 | 의미 |
|---|---|
| `analysis_station_id` | 작업용 역·호선 식별자 |
| `indoor_station_code`, `ridership_station_code` | 각각 원래 내부 지점 코드와 승하차 역 번호 |
| `line`, `station_name` | 내부 지점의 호선·수집 목록 역명. 과거 공식 역명이라는 뜻은 아님 |
| `date`, `hour`, `time_key` | 내부 라벨의 날짜·0~23시·결합 키 |
| `indoor_time_raw` | 원래 내부 시각 라벨 |
| `indoor_pm25_raw`, `indoor_pm25` | 원래 내부 PM2.5 문자열과 숫자형 값 |
| `indoor_status_raw`, `indoor_quality_flag` | 원래 상태와 기초 품질 표시 |
| `boarding`, `alighting` | 해당 시간 열의 승차·하차 인원 |
| `board_alight_count` | 두 값이 모두 있을 때의 승차+하차 건수. 고유 인원·체류 인원·노출량이 아님 |
| `ridership_match_status` | 승하차의 결합·결측 상태 |
| `outdoor_station_code`, `outdoor_station_name`, `outdoor_distance_km` | 초기 대응 실외 측정소와 역 대표점 간 근사 직선거리 |
| `outdoor_time_raw` | 매칭된 실외 자료의 원래 시각 라벨 |
| `outdoor_pm25_raw`, `outdoor_pm25` | 원래 실외 PM2.5 문자열과 숫자형 값 |
| `outdoor_pm10`, `outdoor_so2`, `outdoor_co`, `outdoor_o3`, `outdoor_no2` | 같은 시간의 나머지 실외 항목 |
| `outdoor_match_status` | 실외 대응 보류·관측 부재·PM2.5 결측·값 존재 구분 |
| `time_rule_id` | 현재 모두 `same_label_v1` |

PM2.5·PM10은 농도 항목이며 공식 실외 원본의 표시 단위는 μg/m³, 실외 기체 항목은 ppm이다. 서로 다른 단위의 항목을 합산하지 않는다. 모든 원래 값은 기존 원본·정리본에 보존했다.

## 결측과 품질 표시

### 승하차

- `matched`: 승차·하차 값이 모두 존재. 0명도 실제 값이면 0으로 유지.
- `not_in_source_hours`: 00~04시로 원본 시간대 열이 없음.
- `boarding_missing`, `alighting_missing`, `both_missing`: 해당 날짜의 원래 정리본에서 값 또는 구분 행을 찾을 수 없음. 기존에 보류한 충돌 중복도 영향을 줄 수 있음.
- 한쪽이라도 비어 있으면 승하차 합계도 비워 두었다.

### 실외

- `matched_pm25_present`: 선택한 측정소·시간이 있고 PM2.5 숫자값이 존재.
- `matched_pm25_missing_or_invalid`: 측정소·시간은 있지만 PM2.5 값이 비어 있거나 유효한 비음수 숫자가 아님.
- `selected_station_time_absent`: 선택한 측정소의 해당 시각 자료가 없음. 설치·운영 기간 차이, 결측, 수집 기간 경계 등이 원인일 수 있음.
- `station_coordinate_review_required`: 현충로·율하의 좌표 검토가 필요해 실외 측정소를 배정하지 않음.

가까운 측정소가 결측이라고 시간마다 다른 측정소로 바꾸지 않았다. 특히 현재 좌표에 가까운 측정소가 과거에 없었던 기간은 실외가 빈칸일 수 있다.

### 숫자 변환

빈 문자열·비수치·무한값·음수(실외의 `-999` 포함)는 숫자형 농도 열에서 빈칸으로 표시했다. PM2.5의 원래 문자열은 `_raw` 열에도 남겼다. 결측을 0으로 대체하거나 보간하지 않았다.

내부 농도 숫자가 있더라도 상태코드 공백은 `status_blank_unverified`, 상태가 기재되면 `status_requires_review`로 구분한다. 숫자가 없거나 기초 검사에 맞지 않으면 `missing_or_invalid_value`다. **값이 있다는 표시가 최종 품질 통과 표시가 아니며, 이번 파일은 결합본이지 상태코드 해석까지 완료한 최종 분석 표본이 아니다.**

## 좌표 출처와 남은 한계

- 역: [철도 데이터 포털의 대구교통공사 역위치](https://data.kric.go.kr/rips/M_01_01/detail.do?id=213). 페이지 수정일 2026-02-05의 XLSX를 실제 확보. 원본은 `data/mapping/sources/kric_station_coordinates.xlsx`.
- 실외: [국립환경과학원 대기환경측정소 정보](https://www.data.go.kr/data/15150453/fileData.do). 2024-12-31 현황 CSV를 실제 확보하고 기존 측정소 코드로 20곳 연결. 원본은 `data/mapping/sources/outdoor_station_coordinates_20241231.csv`.
- 추출·대응표: `data/mapping/indoor_station_coordinates.csv`, `outdoor_station_coordinates.csv`, `station_outdoor_crosswalk_initial.csv`.
- 보류 사항: `data/mapping/coordinate_review_required.csv`에 현충로·율하의 원래 좌표와 검토 사유 보관.

현충로·율하의 원래 좌표는 인접 역과 비정상적으로 멀리 떨어져 있고 도·분·초를 소수점 형태로 적은 값일 가능성이 있지만, 독립적으로 확인하지 못해 임의 변환하지 않았다. 10 km 이상 최근접 거리 검토 규칙에 걸린 두 역은 실외 배정을 비웠다. 나머지 55곳의 선택 거리 최댓값은 약 3.136 km다. 이는 거리 기준의 초기 연결이며 지형·급기구 위치·주변 환경·과거 이전·정확한 측지계까지 확인한 것은 아니다.

원래 역 이름과 괄호 부역명은 보존하며, 좌표 파일의 이름 비교에는 호선과 괄호 제거·명시적 개명 별칭을 사용했다. 2024년 말 측정소 현황과 2026년 역 좌표를 과거 모든 날짜의 위치로 검증한 것은 아니므로 분석 시 별도 검토해야 한다. 2025·2026년 실외 값의 수집 당시 잠정성 안내도 그대로 유효하다.

## 검증 범위

저장 파일을 다시 읽어 연도별 행 수와 고유 역·시간 순서, 내부 원래 라벨과 연결 키 일치, 실외 24시의 날짜 이월, 승하차의 빈칸·합계 처리, 실외 좌표 보류 표시, 파일 SHA-256을 점검한다. 내부 원래 값·상태는 역·연도별 표본 342개를 기존 정리본과 대조한다. 최종 수치는 `validation_report.json`에 기록한다.

이번 작업에서 통계적 상관·원인 분석·역 순위·기준초과·관리 효과를 계산하지 않았다. 기존 `data/*/raw`, `prepared` 파일은 덮어쓰지 않았다.
