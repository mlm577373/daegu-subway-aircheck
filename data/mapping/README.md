# 역·시간 대응표와 위치 자료 확인 결과

> 후속 갱신(2026-11-14): 사용자가 시간 의미 미확인 시 같은 시간 라벨 결합을 승인했고, 좌표를 추가 확보하여 실제 결합 파일을 생성했다. 현재 결과는 [`../merged/README.md`](../merged/README.md)를 확인한다. 아래 내용은 그 승인 이전의 초기 조사 기록이며, 현재의 결합 보류 상태를 뜻하지 않는다. 현재 좌표·실외 초기 대응표는 이 폴더의 `indoor_station_coordinates.csv`, `outdoor_station_coordinates.csv`, `station_outdoor_crosswalk_initial.csv`다.

작성일: 2026-11-14. 승인 범위는 **역·시간 대응표 작성 및 위치 정보 확보 가능성 확인**이다. 이 폴더는 결합 준비용 메타데이터이며, 관측자료를 결합한 결과가 아니다. 기존 `raw`, `prepared` 파일은 변경하지 않았다.

## 1. 현재 준비 상태

| 항목 | 결과 | 사용 가능 범위 |
|---|---|---|
| 내부 공기질 ↔ 승하차 역 키 | 57개 지점 전부 1:1 연결, 모호한 연결 0개 | 현 로컬 파일의 역 대응에 사용 가능 |
| 역명 비교 방법 | 호선+동일 역명 49개, 명시적 표기 보정 7개, 개명 확인 1개 | 일반적인 유사 문자열 매칭이나 역 순번 추정은 사용하지 않음 |
| 승하차의 분석 범위 밖 역 | 전체 94개 역 번호 중 37개 | 연결 실패가 아니라 내부 57개 지점 범위 밖인 역. 별도 목록 보존 |
| 승하차 시간 구간 | 05~06시부터 23~24시까지 19개 구간 | 날짜 경계 예시 작성. 00~05시는 자료 없음이며 0으로 채우지 않음 |
| 내부·외부 공기질 평균의 시간 기준 | 평균 구간의 시작/종료 중 어느 쪽 라벨인지 공식 근거 미확인 | **시간별 결합은 아직 실행하지 않음** |
| 역 위치 | 철도 데이터 포털의 실제 좌표 XLSX 제공 페이지·링크 확인 | 파일 다운로드·57개 역 좌표 검증은 아직 하지 않음 |
| 실외 측정소 위치 | 20개 지점의 이름·운영기관과 일치하는 현재 주소 후보 확인 | 좌표·이전 이력 확인 전. 어떤 역에도 실외 측정소를 배정하지 않음 |

`station_key_ready=1`은 역 식별자 연결이 준비됐다는 뜻이다. `hourly_join_ready=0`은 시간 구간과 실외 대응이 미확정이어서 시간별 관측자료 결합을 아직 하면 안 된다는 뜻이다. 관측값의 존재·품질을 보장하는 표시는 아니다.

## 2. 파일과 열 설명

| 파일 | 내용 |
|---|---|
| `station_crosswalk.csv` | 내부 측정지점 코드 ↔ 승하차 호선·역 번호 57개 대응표 |
| `ridership_station_aliases.csv` | 전체 승하차 역 번호·표기별 최초/최종 관찰 날짜·행 수·원본 정리 파일 목록 |
| `ridership_stations_outside_indoor_scope.csv` | 내부 지점에 대응하지 않는 범위 밖 승하차 역 목록 |
| `station_match_issues.csv` | 후보가 없거나 여러 개인 문제 목록. 현재는 헤더만 있음 |
| `time_crosswalk_examples.csv` | 내부 24개·외부 24개 시간 라벨, 승하차 19개 구간의 총 67개 예시 |
| `location_source_inventory.csv` | 공식 위치 자료 제공 경로, 확인 수준, 다음 확인 항목 |
| `outdoor_station_metadata_candidates.csv` | 20개 실외 지점의 현재 주소·운영기관·설치년도 후보. 좌표는 빈칸 |
| `mapping_summary.json` | 대응 건수·준비 상태·미해결 항목 요약 |
| `sources/` | 공식 메타데이터 페이지 HTML과 실제 접속 확인 기록 |

CSV는 UTF-8 BOM이다. `station_crosswalk.csv`의 주요 열:

- `analysis_station_id`: 작업용 식별자 `DG_L호선_승하차역번호`. 현 파일에서 고유하며 공식 발급 코드가 아니다.
- `indoor_station_code`, `indoor_line`, `indoor_station_name`: 원래 내부 지점 식별 정보.
- `canonical_match_name`: 이번 비교용 이름. 과거 공식 역명을 덮어쓰는 값이 아니다.
- `ridership_line`, `ridership_station_code`, `ridership_observed_names`: 연결할 승하차 코드와 관찰된 모든 이름.
- `first_ridership_date`, `last_ridership_date`: 현재 파일에서 관찰한 날짜 범위. 중간 날짜의 완전성·개통일·공식 개명 유효기간을 뜻하지 않는다.
- `match_method`, `verification_status`: 연결 근거와 현재 로컬 파일에서의 검증 수준.
- `location`, `address`: 기존 내부 목록의 장소·주소.
- `latitude`, `longitude`, `outdoor_station_code`: 아직 미확정이므로 빈칸. 주소로 좌표를 임의 생성하거나 거리 계산을 하지 않았다.
- `station_key_ready`, `hourly_join_ready`: 역 키 준비와 실제 시간별 결합 준비를 구분한 표시.

| 내부 표기 | 승하차 표기·번호 | 처리 |

| 교대(대구) | 교대 / 1호선 1280 | 동일 |

| 반월당 1호선 | 반월당1 / 1300 | 2호선과 다른 작업용 역 키 유지 |
| 반월당 2호선 | 반월당2 / 2300 | 1호선과 다른 작업용 역 키 유지 |

수성알파시티 개명은 [대구교통공사 공식 시각표 자료 설명](https://www.data.go.kr/data/3033376/fileData.do)에서 **2024-10-10 기존 대공원역의 역명 변경 반영**으로 확인했다.

현재 승하차 정리본에서 수성알파시티 표기는 2024-10-10~2024-10-31의 44행에 나타나지만, 다른 기간에는 2026년까지도 대공원 표기가 있다. 따라서 개명일 이후 이름이 항상 바뀌어 있다고 가정하거나, 날짜와 역명만으로 행을 버리지 않는다. 연결 키는 호선과 역 번호 `2380`이며 두 이름 모두 허용한다. 별칭 목록의 최초·최종 관찰 날짜 사이가 연속된 표기 유효기간이라는 의미도 아니다.

## 4. 시간 대응: 확정한 부분과 미확인 부분

현재 파일에서 실제 관찰한 표시 방식은 다음과 같다.

| 자료 | 원본 라벨 | 확인한 것 | 아직 확인하지 못한 것 |
|---|---|---|---|
| 내부 공기질 | `YYYY-MM-DD:00`~`:23` | 0~23 시간 라벨. 공식 지도는 1시간 평균으로 표기 | 예를 들어 `06`이 05~06시 평균인지 06~07시 평균인지 |
| 지상 공기질 | `YYYY-MM-DD 01`~`24` | 1~24 시간 라벨 | 평균 구간과 시각 라벨의 정확한 관계 |
| 승하차 | `h05_06`~`h23_24` | 열 자체가 시간 구간을 표시 | 경계 정각의 집계 포함 방식 등 세부 정의 |

특히 기존 정리본의 `hour_ending`은 수집 스크립트가 붙인 열 이름이다. **이 이름만으로 제공기관이 시간 종료 시각으로 정의했다고 판단하지 않는다.**

`2025-01-01 24`라는 달력 시각은 `2025-01-02 00:00`으로 표현해야 한다. 그러나 그 값의 평균 대상 구간이 무엇인지는 별도 문제다. 이를 같은 날짜의 00시로 잘못 옮기지 않는다.

`time_crosswalk_examples.csv`는 다음을 구분한다.

- `calendar_label_time`: 라벨을 달력상의 시각으로만 해석한 예시. 관측 구간의 확정값이 아님.
- `interval_start_confirmed`, `interval_end_confirmed`: 승하차의 명시적 구간만 작성. 공기질은 미확인이라 빈칸.
- `candidate_*_if_start_label`, `candidate_*_if_end_label`: 시작 라벨·종료 라벨이라는 두 가정에서의 예시. 확정 규칙이 아니며 둘 중 하나를 자동 선택하지 않음.
- `status`, `allow_hourly_join`: 미확인 상태와 결합 보류를 표시. 시간별 결합을 허용하는 행은 현재 없음.
- `timezone_convention`: 한국 현지 시각을 사용한다는 작업상 전제. 제공기관의 시간 메타데이터를 최종 확인할 항목으로 남김.

표시용 예시에는 구간 경계를 사용했지만 `[시작, 종료)` 같은 경계 포함 규칙도 자료 제공자의 확정 규칙이라고 주장하지 않는다. 상관계수가 가장 크게 나오는 시차를 골라 원본 시간 의미를 확정하지 않는다.

확인한 공식 [실내공기질 지도](https://www.inair.or.kr/info/map.html)의 1시간 평균 표시와 기존 자료조회 화면·소스만으로는 시작/종료 기준을 확정하지 못했다. 외부 공기질도 이번에 확인한 공식 조회 화면·설명에서 이 세부 정의를 찾지 못했다. 검색 실패가 정의가 존재하지 않는다는 뜻은 아니다. 후속 단계에서는 공식 도움말·자료 사전·측정자료 처리 지침을 우선 확인하고, 해결되지 않으면 제공기관 설명이 필요하다. 이번 작업에서 기관에 문의를 발송하지는 않았다.

## 5. 위치 정보 확보 가능성

### 역 좌표: 공식 파일 제공 확인, 내용 검증 전

- [철도 데이터 포털: 대구교통공사 역위치(위도,경도)](https://data.kric.go.kr/rips/M_01_01/detail.do?id=213)
- 2026-11-14 실제 접속으로 페이지 제목, 제공기관, XLSX 형식, 다운로드 링크를 확인했다.
- 설명에 철도운영기관명·선명·역명·경도·위도가 기재되어 있고, 페이지의 수정일은 2026-02-05다.
- [페이지에 제공된 다운로드 경로](https://data.kric.go.kr/rips/dataset/download.file?type=filedata&id=213&operation=1)는 확인만 했으며 파일은 내려받지 않았다. 다운로드 응답의 성공·파일 내용·좌표계·대상 57개 역의 포함 여부는 아직 검증하지 않았다.
- 역 대표 좌표와 승강장 측정기·출입구·급기구 좌표는 서로 다르다. 최신 좌표가 과거의 모든 위치를 뜻하지도 않는다.

### 실외 측정소: 현재 주소 후보 20개 확인, 좌표·이전 이력 확인 전

[에어코리아 측정소 정보](https://www.airkorea.or.kr/web/stationInfo?pMENU_NO=93)의 실제 HTML에서 수집 목록의 20개 이름과 대구 운영기관이 일치하는 항목을 각각 하나씩 찾았다. 현재 주소·운영기관·설치년도·측정항목을 후보 메타데이터로 보관했다. 이름과 운영기관으로 후보를 찾은 것이며 독립적인 좌표·측정소 코드 교차 검증을 마친 것은 아니다.

이 페이지 확인 결과만으로 위·경도나 과거 이전 이력을 확정하지 못했다. 설치년도를 해당 기간 전체의 정상 운영 근거로 삼지 않는다. 지상 좌표는 공식 측정망 제원 등에서 코드와 함께 확인하고, 분석 기간의 이전·운영 이력도 검토해야 한다.

### 대체 경로: 2호선 출구 좌표

[공공데이터포털의 2호선 역별 출구별 위치정보](https://www.data.go.kr/data/15133920/fileData.do)는 공식 설명에 역명·출구번호·위도·경도가 있다. 2호선에 한정되며 여러 출구 중 대표점을 정해야 하고 센서·급기구 좌표가 아니므로, 역 대표 좌표가 미흡할 때 검토할 대체 경로다. 실제 파일은 다운로드하지 않았다.

## 6. 다음 실행 전에 결정·확인할 사항

1. 공식 역 좌표 파일과 실외 측정소 좌표·이력 자료를 추가 확보할 범위 승인.
2. 내부·외부 평균 구간의 라벨 정의 확인. 미해결 상태에서 시간별 관측값을 억지로 연결하지 않음.
3. 위치와 운영 기간을 검토한 뒤 역별 실외 측정소 후보·거리·선정 이유를 제시하고 매칭 규칙 승인.
4. 이 조건을 충족하면 별도 승인 후 내부 자료 기준의 left join을 실행하고, 행 수·결합 손실·품질 상태·결측을 보고.

이번 결과는 1:1 역 키를 준비하고 시간·공간 결합의 미확인 사항을 분리한 단계다. 실제 시간별 결합 데이터나 실내외 분석 결과가 만들어진 것은 아니다.
