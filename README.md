# 대구 지하철역 미세먼지 분석

GitHub: [mlm577373/daegu-subway-aircheck](https://github.com/mlm577373/daegu-subway-aircheck)

대구 기후·환경·탄소중립 공공데이터 공모전을 위한 지하철 승강장 PM2.5 분석 프로젝트다. 반복적으로 농도가 높은 역·시간대와 관리 점검의 필요성을 살펴보는 것이 목표이며, 세부 분석은 계획 단계다.

## 현재 상태

- 내부 공기질 57개 지점, 지상 대기질, 시간대별 승하차 자료 수집.
- 공통 기간: 2021년 4월~2025년 4월, 2026년 1~4월의 총 53개월.
- 연도별 실제 결합 CSV 6개, 총 2,173,944행 생성 및 결합 검증 완료.
- 시간 평균 구간의 기준 시각은 미확인이다. 사용자 승인에 따라 같은 시간 라벨로 결합했고, 이 가정을 데이터 설명서에 기록했다.
- 55개 역은 거리 기준의 실외 측정소 초기 대응을 적용했다. 현충로·율하는 좌표 형식 검토가 필요해 실외 값만 비워 두었다.
- 통계 분석·모델 학습·관리 효과 검증은 아직 수행하지 않았다.

## 데이터와 Git 관리

Git에는 코드와 문서를 저장한다. 원본, 실제 결합 CSV, 좌표 파일, 다운로드 HTML/JSON, SQLite 캐시와 로컬 Python 라이브러리는 `.gitignore`로 제외한다. 파일은 로컬 프로젝트에 그대로 보관하며 Git 업로드 대상으로 추가하지 않는다.

결합 파일의 로컬 위치는 `data/merged/merged_hourly_2021.csv`~`merged_hourly_2026.csv`다. 이 저장소를 복제하는 것만으로 관측자료가 제공되는 것은 아니다. 각 데이터 설명서에서 공식 출처를 확인해야 한다.

Python 스크립트는 현재 로컬 수집 캐시와 대응표를 이용하는 단계별 작업 코드다. 빈 폴더에서 전체 자료를 자동 재구축하는 단일 실행 과정까지 정비된 상태는 아니다. 네트워크 수집 스크립트는 실행 범위와 대상 기간을 먼저 확인한다.

Python 외부 의존성은 `requirements.txt`에 기록한다. 현재 XLS 읽기용 `xlrd==2.0.2`를 사용하며, 기존 스크립트는 로컬 `data/_tools` 경로도 확인한다. 새 환경에서는 가상환경에서 `python -m pip install -r requirements.txt`로 설치할 수 있다.

## 분석 시 주의

같은 시간 라벨의 결합이 정확히 같은 평균 구간임을 입증한 것은 아니다. 실외 측정소는 역 출입구나 급기구에서 측정한 값이 아니며, 현재 위치의 과거 대표성도 추가 검토가 필요하다. 승하차 건수는 승강장 체류 인원이나 개인 노출량이 아니다. 결측과 품질 상태를 확인한 뒤 분석 표본을 정한다.

추가 작업은 범위를 먼저 제시하고 사용자 승인 후 진행한다. `task.md`는 프로젝트 전체 일정표가 아니라 해당 작업만 추적한다.
