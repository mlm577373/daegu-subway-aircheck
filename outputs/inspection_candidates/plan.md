# 우선 점검 후보 선정 계획

## 대상과 표본

역별 비교기간은 온전한 연도인 2022~2024년으로 고정한다. 전체 수집기간은 별도 기본 패턴 보고서를 참조한다. 실내 수치가 유한한 0 이상이고 상태가 공백인 잠정 표본을 사용하며 공식 정상 판정으로 해석하지 않는다. 기본 관측률 90% 이상, 월별 지표는 월 관측률 75% 이상을 요구한다. 36개월 중 최소 30개월이 유효해야 반복성을 평가한다.

## 여섯 관점

1. 평상시 수준: 중앙값(평균 병기).
2. 고농도: 전체 잠정 표본의 통합 90백분위수를 공통 탐색 기준으로 고정하고 기준 이상 시간 비율, 역별 95백분위수, 최장 연속시간을 병기한다. 연속시간은 달력상 1시간 간격만 연결한다. 법정 기준이 아니다.
3. 반복성: 같은 달에 관측률을 충족하는 역이 40개 이상일 때 월별 중앙값 상위 25%에 속한 월의 비율. 연도별 중앙값 상위 25%에 속한 연도 수도 병기한다.
4. 실외 대비: 동시 관측 실내-실외 차이의 중앙값. 실내 유효 표본 대비 동시 관측률 90% 이상인 역만 평가한다. 현충로·율하는 평가 불가이며 0점으로 대체하지 않는다. 비교 시각은 기존 same_label_v1 가정을 따른다.
5. 같은 시각 상대 수준: 유효한 역이 40개 이상인 시각의 역별 농도에서 그 시각 전체 역 중앙값을 뺀 차이의 중앙값. 평가 가능 시간이 기대 시간의 90% 이상인 역만 사용한다. 본인도 비교 중앙값에 포함된다.
6. 이용 겹침: 고농도 시간의 승하차 합 / 실내·승하차 동시 관측 시간의 승하차 합. 시간별 승하차 기대 19시간(05~23시)에 대해 동시 관측률 90% 이상일 때 평가한다. 고농도 시간 승하차 합도 병기하되 실제 노출 인원으로 해석하지 않는다.

## 후보 규칙

각 관점의 대표 지표를 평가 가능한 역 사이에서 상위 25% 기준(75백분위수 이상, 경계 동률 포함)으로 표시한다. 1~5 중 3개 이상이면 '다수 지표 중첩 후보', 2개면 '복수 지표 후보', 1개면 '개별 지표 주목', 없으면 '선정 기준 미해당'이다. 이는 가중 종합점수나 관리 순위가 아니라 근거가 몇 관점에서 겹치는지 표시하는 규칙이다. 6은 이용과의 겹침을 설명하는 보조 표시이며 단독 선정이나 등급 상승에 사용하지 않는다. 실외 비교 불가인 역은 4개 농도 관점만으로 판정되므로 해석 시 제한을 명시한다.

기준의 자의성을 확인하도록 상위 20%·30%로 바꾼 후보 여부도 저장한다. 또한 실외 지표는 동시 관측률 95%를 요구했을 때의 평가 가능 여부, 같은 시각 지표는 실외 연결 유무와 관계없이 계산한다. 원인 분석은 이번 범위에 포함하지 않는다.
